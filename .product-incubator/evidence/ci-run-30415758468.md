## Result

CodeQL passed. The static/type/coverage job passed. Linux and macOS passed on
CPython 3.11 and 3.14. Windows 3.11 and 3.14 failed the same three test
assertions; product execution, install, and earlier E2E steps were otherwise
successful.

## Root cause

1. Windows reports opening a directory as `PermissionError`, while POSIX reports
   `IsADirectoryError`; the test asserted one platform-specific error phrase.
2. Python `print` writes native CRLF on Windows. Two tests incorrectly asserted
   POSIX LF even though ReproBrief intentionally preserves captured bytes.

## Focused correction

- Validate that a recipe path is a regular file before opening it, producing one
  deterministic cross-platform error.
- Assert `os.linesep` for output generated by Python `print`.
- Keep exact output capture, the Windows matrix, coverage floor, and all security
  boundaries unchanged.

The correction received a local 57-test regression run, 87% branch coverage,
Ruff, strict mypy, Bandit, detect-secrets, pip-audit, and Claim Gate before the
normal follow-up push.
